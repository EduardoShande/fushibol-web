# Fushibol · Web app

Build web (SPA) de la app Fushibol, exportada con Expo (`npx expo export --platform web`).
Se sirve como sitio estatico. `404.html` es una copia de `index.html` para que el
enrutado del cliente (por ejemplo `/login`) funcione en GitHub Pages.

- App en vivo (Expo): https://eduardo123-test-golazo.expo.app
- Dominio: app.fushibol.com (ver CNAME)
